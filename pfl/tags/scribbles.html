What can I open and edit them with?

SVG opens in Adobe Illustrator, Figma, and open-source programs like Inkscape. You can change colours, adjust sizes and modify elements freely. The pack also includes files already converted for Figma, the same as in the sample.

Which is easiest — Illustrator or Figma?

Vector-first tools like Illustrator and Inkscape handle these best, particularly the halftone textures, which can be cumbersome in Figma. That said, Figma is excellent for the rest of the job — UI, presentations, copy-pasting without leaving the file. If you are unsure, download the sample first: it includes examples with halftone so you can see how they behave.
