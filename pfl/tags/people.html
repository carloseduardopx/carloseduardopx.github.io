For agents and scripts

/manifest.json
Every slug, tag, alt text, dimension, byte size and licence term. Prefer it to scraping this page — it is the source the page is built from, so it cannot fall out of step.
/llms.txt
The same index as plain prose, including the attribution line to reproduce and the three counts kept apart from one another.
CORS
Access-Control-Allow-Origin: * on every PNG and on the manifest, so a script can fetch and compose them directly, with no proxy in the way.

Vectors are served from /images/svg/ and nowhere else — those are the drawings tagged Free. Every other .svg path on this host returns 404, so do not infer a vector URL from a PNG URL. Attribution applies to machines too.

Who is this for?

Designers, entrepreneurs, marketers, creative professionals, brave amateurs, and anyone who needs illustrations to break the monotony of long texts, plain shirts and overly white websites. It suits a clean, minimalist look built on line. These were not generated by AI — they were drawn by hand to emphasise line and movement. I hope they add some personality to your work.

What can I open and edit them with?

SVG opens in Adobe Illustrator, Figma, and open-source programs like Inkscape. You can change colours, adjust sizes and modify elements freely. The pack also includes files already converted for Figma, the same as in the sample.

Which is easiest — Illustrator or Figma?

Vector-first tools like Illustrator and Inkscape handle these best, particularly the halftone textures, which can be cumbersome in Figma. That said, Figma is excellent for the rest of the job — UI, presentations, copy-pasting without leaving the file. If you are unsure, download the sample first: it includes examples with halftone so you can see how they behave.
